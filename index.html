Locked apps

Connect the locks on your iPhone

Orrery can't close other apps by itself, so iOS Shortcuts does the redirect. You set this up once. Step names may differ slightly on your iOS version.

Shortcut 1, named “Orrery Gate”

  1. Open Shortcuts and tap +.
  2. Add Get File. Choose iCloud Drive, turn off Show Document Picker, enter orrery-pass.txt, and turn off Error If Not Found.
  3. Add Get Dates from Input, using that file.
  4. Add If: Dates is after Current Date. Inside it, add Stop This Shortcut.
  5. After End If, add Open URLs and set it to Shortcut Input.

Shortcut 2, named “Orrery Pass”

  1. Add Get Numbers from Input, using Shortcut Input.
  2. Add Adjust Date: add those numbers, in minutes, to Current Date.
  3. Add Text and insert Adjusted Date, formatted as ISO 8601.
  4. Add Save File. Turn off Ask Where to Save, use the path orrery-pass.txt, and turn on Overwrite If File Exists.

One automation per locked app

  1. In Shortcuts, open Automation and tap +. Choose App, pick the app, and select Is Opened and Run Immediately.
  2. Tap that app in the list above and copy its automation link. In a new blank automation, add Text and paste the link.
  3. Add Run Shortcut: Orrery Gate, with that Text as input.

The gate adds friction. It isn't a hard lock, since you can always delete the automation. For a hard stop, add an App Limit in Settings under Screen Time and let someone you trust set the passcode.
